# AAPC 2.0 — Array Arena Programming Contest
### Beginner-Friendly Solutions Repository

Welcome to the beginner-friendly solutions repository for all 7 problems of the **Array Arena Programming Contest (AAPC 2.0)**.

All solutions in this repository are written in simple, readable, and standard code suited for students and competitive programming beginners across **C**, **C++**, **Python 3**, and **Java**.

## 🚀 How to Run the Code

### C++ (`solution.cpp`)
Standard beginner C++ using `cin` and `cout`:
```bash
g++ solution.cpp -o solution
./solution
```

### C (`solution.c`)
Standard C using `scanf` and `printf`:
```bash
gcc solution.c -o solution
./solution
```

### Python 3 (`solution.py`)
Standard Python using `input()`:
```bash
python solution.py
```

### Java (`Solution.java`)
Standard Java using `Scanner`:
```bash
javac Solution.java
java Solution
```
